# 🏦 Simple Bank Account

A simple **Bank Account management program** built with Python. This project demonstrates basic banking operations through a simple command-line interface.

## ✨ Features

- 💰 Check account balance
- ➕ Deposit money
- 💸 Withdraw money
- 🏦 Manage a basic bank account
- 🖥️ Simple command-line interface
- 🐍 Built with Python

## 🛠️ Technologies Used

- Python

## ▶️ How to Run

1. Make sure Python is installed on your computer.
2. Clone this repository:

```bash
git clone https://github.com/laibashahadat/Simple-Bank-Account.git
```

3. Open the project folder.
4. Run the Python file:

```bash
python "project 7 . #Simple Bank Account.py"
```

## 🎯 Purpose

This project was created to practice Python programming concepts such as variables, functions, conditional statements, loops, user input, and basic calculations.
